# Inbox: models, art and files for the Kata mod

Drop anything here for the Kata mod to be built from: models (Blockbench `.bbmodel`, `.json`, `.obj`),
textures (`.png`), sounds (`.ogg`), screenshots, sketches, mock-ups, notes. Nothing in here is shipped as it is;
it's looked at and turned into the mod's real assets and code.

How to drop files in (no tools needed):

1. Open this folder on GitHub, on the `claude/minecraft-aot-map-uucuom` branch.
2. **Add file > Upload files**, drag the files in, and commit.
3. Say what they're for (for example "the locker wall model for the menu"), and anything about how it should look or move.

Keep a folder per thing if there are several files to one idea, e.g. `inbox/locker-wall/`.

## What's being built from it

- **The Kata interface overhaul**: the menus and screens of the Kata server (not the shared Kata Core),
  starting from the locker wall model.
