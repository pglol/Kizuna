Pictures for the launcher, one set per server (then point to them in servers/hub.json):

- `<id>-icon.png`: square, 128x128 or bigger. Shown in the server rail.
- `<id>-logo.png`: your logo/wordmark on a transparent background, about 900x350.
- `<id>-bg.png` (or `.mp4`/`.webm`): a 1920x1080 in-game screenshot or short clip, shaders on.
  Keep the left side darker or emptier: the logo and Play button sit there.
- News pictures: 600x350 screenshots, any name.

Everything here goes out to every player, so only use pictures you made or have permission to use.
